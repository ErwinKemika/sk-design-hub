# SK Design Hub

Build a full multi-page company profile website for SK.INTERIOR.DESIGN, a premium construction & interior company established in 2003, offering four services: Civil Construction (Sipil), Steel Construction (Konstruksi Baja), Interior Design, and Custom Furniture (kitchen sets, wardrobes, tables).

Design Direction

Reference the layout and structure of this architecture template: https://html.ditsolution.net/arcke/index-3.html — full-width hero slider, large bold headline typography, image + text about section with a stats/counter block, project/portfolio grid with hover overlay, big number counters section, testimonial carousel, blog/news grid, multi-column footer.

Color palette — Black & Gold luxury theme (matches our logo):

Primary background: deep black / near-black (#0D0D0D or #111111)

Primary accent: glossy warm gold (#B08D57 to #D4AF6A gradient range)

Secondary background: dark charcoal (#1A1A1A) for alternating sections

Text on dark: off-white (#F5F3EE)

Use gold as accent only (buttons, borders, icons, numbers, hover states) — not as a dominant fill color, to keep it elegant and not overwhelming.

Typography: elegant serif or modern high-contrast serif for headings (like Playfair Display or Cormorant), clean sans-serif for body text (like Inter or Poppins). Generous letter-spacing on labels/eyebrow text (uppercase, small, gold color).

Logo: Black & gold "SK" monogram with the word "INTERIOR" beneath it (transparent PNG will be uploaded separately — use placeholder text logo "SK.INTERIOR.DESIGN" until then).

General requirements

Fully responsive (mobile, tablet, desktop).

Sticky/transparent-to-solid navbar on scroll, dark background, gold hover states on nav links.

Smooth scroll and subtle fade-in animations on scroll (like the reference template).

Use placeholder professional stock-style images for construction/interior/furniture (can be replaced later with real project photos).

All page copy should follow a confident, professional-but-warm Indonesian tone (Bahasa Indonesia), consistent with the sample text provided above — extend similarly for any additional filler content needed.

Leave clearly marked placeholders in brackets [ ] for: address, phone/WhatsApp number, email, project count, client count, team count, social media handles, and testimonial content — client will fill these in later.
